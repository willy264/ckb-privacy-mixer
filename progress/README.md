# Historical Progress Records

Files in this directory record what the project reported, attempted, or planned at the stated time. Unless a page explicitly links current reproducible evidence, its deployment, transaction, test, security, and completion statements have not been independently re-verified as part of the corrected-V1 work.

The pre-audit mixer is the preserved legacy prototype. Its Pudge activity, coordinator-owned state, circuit, contracts, and SDK APIs are not corrected-V1 evidence. Current implementation status and limitations are maintained in [`docs/status.md`](../docs/status.md) and [`docs/known-limitations.md`](../docs/known-limitations.md); current screenshot provenance is in [`docs/evidence/README.md`](../docs/evidence/README.md).

Planning artifacts have an additional boundary in [`progress_plan/README.md`](progress_plan/README.md).
